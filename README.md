# What Should I Eat? — V0

A tiny, serverless decision-making web app.

## Run locally

Open `index.html` in a browser.

## Deploy with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `app.js`.
3. In the repository, open Settings → Pages.
4. Choose "Deploy from a branch".
5. Select the `main` branch and `/ (root)`.
6. Save and open the generated GitHub Pages URL.

No backend, database, API, or server is required for this version.
